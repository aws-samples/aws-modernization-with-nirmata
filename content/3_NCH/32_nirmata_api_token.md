The Nirmata API token authenticates the `nctl` CLI and allows it to communicate with the Nirmata Control Hub on your behalf. Without this token, `nctl` cannot register clusters, deploy policies, or manage resources in your Nirmata tenant.

Log in to [Nirmata](https://nirmata.io/security/login.html), go to *Settings → Profile*, click **Generate API Key**.

:image[Generate API Key in Nirmata profile settings]{src="/static/images/nctl-createapikey.png" width=900}

You can retrieve API key later but you also can copy it and keep it handy for next steps.
